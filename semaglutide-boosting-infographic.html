What happens when a user searches “Semaglutide”

A step-by-step, click-through view of how the search engine decides which paid content jumps to the top — and how many actually do.

Semaglutide

The content that matched

Five pieces of content came back from the search. Each carries labels describing what it is — brand originator, sponsored, keyword-tagged, or a plain active-ingredient match. The number in the corner is its raw relevance score.

2

Sorting into piles

The function drops each result into one of four buckets based on its labels and whether the user qualifies (profession, location, campaign dates). Press the button to sort them.

Tag matches

Paid to appear for the keyword “Semaglutide”. These go into a lottery.

Originators

Sponsored original brand-name medicine. All qualifying ones are kept.

Other sponsored

Other paid content the user qualifies for. (None in this scenario.)

Everything else

Normal results, ranked by relevance score.
3

The lottery: Extensior vs SEMAGARD

Both paid for the same keyword, so only one can take the top slot. The winner is drawn using the real formula from the code: score × random^(1 / weight). A higher paid weight means better odds — but it’s never guaranteed. The loser drops back into the normal results.

The final ranked list

The function stitches everything together: the lottery winner first, then the originator (Wegovy), then the normal results by score — with the lottery loser mixed back in. Run the lottery above, then build the list.

⚠️ The thing worth noticing

Two paid results (the lottery winner and Wegovy) end up sitting above the organic “Semaglutide” ingredient results — but only the first one is stamped with the “Sponsored” label. Wegovy gets the premium top position without wearing the badge. That’s the behaviour behind the “2 boosted results” observation.
